This is a patch file for Spriggan Lunar Verse to translate it to english.

MD5SUM of "Spriggan - Lunar Verse (Japan).bin" = 173d741ec9483c87e20085a0f9b4098a

How to apply this patch:

1. Get xdelta3 to apply patch

2. Ensure your Spriggan Lunar Verse .bin file has the same hash as mine. If not go find one that does

2. Run this command: xdelta3 -d -s "Spriggan - Lunar Verse (Japan).bin" "Spriggan_EN.xdelta" "Spriggan - Lunar Verse (En).bin"

3. .cue files are just text, either copy and edit the .cue file to point to this new filename, or change the filename of our new .bin file to be what was previously there

4. Play game
